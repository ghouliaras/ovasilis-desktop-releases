This repository hosts the installers and update metadata for **Vasilis Orders**, a private desktop application built for a client. It contains **no source code**.

Installed copies of the app check this repository for new versions and update themselves automatically.

## Download

Get the latest installer from the [Releases page](https://github.com/ghouliaras/ovasilis-desktop-releases/releases/latest): `Vasilis-Orders-Setup-<version>.exe`.

## Maintainer notes

- Each release must include the installer (`.exe`), its `.blockmap` and `latest.yml` — the app uses them to find and download updates.
- Don't delete published releases or make this repository private, or installed copies will stop receiving updates.
